# 语法说明（简体中文）

`.alua` 采用**嵌入式方言**：文件主体为标准 Lua（转译器透传）；仅顶层 `async function` 区域使用下文文法并被降级为状态机。

## 文件级（splice）

```
file ::= { lua_passthrough | async_function }
```

- **lua_passthrough**：任意标准 Lua 文本（含普通 `function`、`local`、表、控制流等），**不解析、不改写**。
- **async_function**：必须出现在顶层（不在另一块内部）；由 splice 按块嵌套匹配到对应 `end`。
  - 块开启关键字含：`function` / `if` / `do` / `try` / `repeat`（`while`/`for` 由其后的 `do` 加深）。

透传区与 async 区交错顺序保留。若存在 async，生成文件顶部有：

```lua
local Task = require("runtime.task")
```

## 词法（仅 async 区域）

- **空白**：空格、制表、回车、换行
- **注释**：`--` 行注释；`--[[ ... ]]` / `--[=[ ... ]=]` 长注释
- **关键字**：`async` `function` `end` `local` `return` `await`
  `if` `then` `else` `elseif` `while` `do` `for`
  `try` `catch` `finally` `rethrow`
  `and` `or` `not` `true` `false` `nil` `repeat` `until`
- **名字 / 数字 / 字符串**：与常见 Lua 子集相同
- **符号**：`( ) [ ] { } , ; . : = + - * / #`
  `== ~= < <= > >= ..`

## 异步函数

```
async_function ::=
  "async" "function" Name "(" [ Name { "," Name } ] ")"
  block
  "end"
```

## 语句

```
block ::= { statement }

statement ::=
    "local" Name "=" expression
  | assign_target "=" expression
  | expression
  | "return" [ expression ]
  | "rethrow" [ expression ]
  | if_stmt | while_stmt | for_stmt | try_stmt

assign_target ::= Name { "." Name | "[" expression "]" }

if_stmt ::=
  "if" expression "then" block
  { "elseif" expression "then" block }
  [ "else" block ]
  "end"

while_stmt ::= "while" expression "do" block "end"

for_stmt ::=
  "for" Name "=" expression "," expression [ "," expression ]
  "do" block "end"

try_stmt ::=
  "try" block
  [ "catch" [ Name ] block ]
  [ "finally" block ]
  "end"
```

约束：`try` 至少带 `catch` 与/或 `finally` 之一。

### try / catch / finally 语义

- `try` 体内 `await` 若对应 Task **rejected** 或 **canceled**，跳到 `catch`（若有），否则进入 `finally` 并在其后向外传播。
- `catch Name`：将失败原因绑定到 `Name`（取消错误形如 `{ canceled = true, ... }`）。
- `finally`：**无论成功、捕获或即将传播**，在离开 try 区域前执行。
- `return` 若位于带 `finally` 的 try/catch 内：先跑 `finally`，再兑现外层 Task。
- `rethrow` / `rethrow expr`：标记传播；有 `finally` 则先执行再 rejected/canceled。

匿名 `function (...)` **不能**写在 async 体内（方言子集无此表达式）；把闭包放在宿主 Lua 透传区即可。

## 表达式（优先级由低到高）

```
or < and < 比较 < .. < + - < * / < 一元 < 后缀
```

```
unary  ::= "await" unary | "not" unary | "#" unary | "-" unary | postfix
postfix ::= primary { call | "." Name | "[" expr "]" | ":" Name call }
primary ::= Number | String | true | false | nil | Name | "(" expr ")" | table
table   ::= "{" [ field { "," field } ] "}"
field   ::= Name "=" expr | "[" expr "]" "=" expr | expr
```

## 语义

- 调用 `async function` 返回 **Task**（状态：`pending` → `fulfilled` | `rejected` | `canceled`）。
- `await exp`：fulfilled → 取值为结果；rejected → 走 catch 或外层 rejected；canceled → 走 catch 或外层 canceled。
- async 体内 `local` / 赋值名存入 `self._locals`。

## 取消（运行时，非语法关键字）

见 `runtime/cancellation.lua` 与设计说明：

- `Cancellation.scope(fn)` / `cancel_scope`：链接父 token、压 ambient，返回 Task。
- `Cancellation.current()`：读 ambient；`delay(ms, ct?)` 默认读 ambient。
- 显式 `ct` 参数仍可用。编译器注入 ambient 为后续阶段。

## 组合子（运行时）

- `Task.when_all(tasks|...)`：等全部结算；**任一 reject → reject**（优先于 cancel）；否则**任一 cancel → cancel**；否则值为结果数组。
- `Task.when_any(tasks|...)`：先结算者胜；兑现 `{ index, value, status, task }`。
