# 语法说明（简体中文）

`.alua` 采用**嵌入式方言**：文件主体为标准 Lua（转译器透传）；仅顶层 `async function` 区域使用下文文法并被降级为状态机。

## 文件级（splice）

```
file ::= { lua_passthrough | async_function }
```

- **lua_passthrough**：任意标准 Lua 文本（含普通 `function`、`local`、表、控制流等），**不解析、不改写**。
- **async_function**：必须出现在顶层（不在另一块内部）；由 splice 按块嵌套匹配到对应 `end`。

透传区与 async 区交错顺序保留。若存在 async，生成文件顶部有：

```lua
local Task = require("runtime.task")
```

## 词法（仅 async 区域）

- **空白**：空格、制表、回车、换行
- **注释**：`--` 行注释；`--[[ ... ]]` / `--[=[ ... ]=]` 长注释
- **关键字**：`async` `function` `end` `local` `return` `await`
  `if` `then` `else` `elseif` `while` `do` `for`
  `and` `or` `not` `true` `false` `nil` `repeat` `until`
- **名字 / 数字 / 字符串**：与常见 Lua 子集相同
- **符号**：`( ) [ ] { } , ; . : = + - * / #`
  `== ~= < <= > >= ..`

## 异步函数

```
async_function ::=
  "async" "function" Name "(" [ Name { "," Name } ] ")"
  block
  "end"
```

## 语句

```
block ::= { statement }

statement ::=
    "local" Name "=" expression
  | assign_target "=" expression
  | expression
  | "return" [ expression ]
  | if_stmt | while_stmt | for_stmt

assign_target ::= Name { "." Name | "[" expression "]" }

if_stmt ::=
  "if" expression "then" block
  { "elseif" expression "then" block }
  [ "else" block ]
  "end"

while_stmt ::= "while" expression "do" block "end"

for_stmt ::=
  "for" Name "=" expression "," expression [ "," expression ]
  "do" block "end"
```

`if` / `while` / `for` 的分支与循环体内**允许** `await`（状态机拆分）。

## 表达式（优先级由低到高）

```
or < and < 比较 < .. < + - < * / < 一元 < 后缀
```

```
unary  ::= "await" unary | "not" unary | "#" unary | "-" unary | postfix
postfix ::= primary { call | "." Name | "[" expr "]" | ":" Name call }
primary ::= Number | String | true | false | nil | Name | "(" expr ")" | table
table   ::= "{" [ field { "," field } ] "}"
field   ::= Name "=" expr | "[" expr "]" "=" expr | expr
```

说明：

- `await` 右结合；方法调用生成 Lua 的 `obj:method(...)`。
- `and`/`or` 中若含 `await`，await 按出现顺序提前求值（见设计说明）。

## 语义

- 调用 `async function` 返回 **Task**。
- `await exp` 要求 `exp` 为 Task（或可 `andThen`）；结果写入状态机临时量后再赋给用户变量。
- async 体内 `local` / 赋值名存入 `self._locals`。
