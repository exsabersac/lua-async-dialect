# MVP 语法（简体中文）

本文描述当前转译器实际接受的文法。未列出的 Lua 特性一律**不支持**。

## 词法

- **空白**：空格、制表、回车、换行
- **行注释**：`--` 直到换行
- **关键字**：`async` `function` `end` `local` `return` `await`
- **名字**：`[A-Za-z_][A-Za-z0-9_]*`（非关键字）
- **数字**：整数或小数（如 `10`、`3.14`）
- **字符串**：`'...'` 或 `"..."`，支持 `\n` `\t` `\\` `\'` `\"`
- **符号**：`( ) , = + - * /`

## 文件

```
file ::= { async_function }
```

顶层只能是若干 `async function`，不能写裸语句。

## 异步函数

```
async_function ::=
  "async" "function" Name "(" [ Name { "," Name } ] ")"
  block
  "end"
```

## 语句块与语句

```
block ::= { statement }

statement ::=
    "local" Name "=" expression
  | Name "=" expression
  | expression                    -- 表达式语句（多为调用或 await）
  | "return" [ expression ]
```

`return` 后是否跟表达式，由下一 token 是否像表达式开头启发式判断（名字 / 字面量 / `(` / `await` / `-`）。

## 表达式（优先级由低到高）

```
expression ::= add

add    ::= mul { ("+" | "-") mul }
mul    ::= unary { ("*" | "/") unary }
unary  ::= "await" unary | "-" unary | primary

primary ::=
    Number
  | String
  | Name { call_suffix }
  | "(" expression ")" { call_suffix }

call_suffix ::= "(" [ expression { "," expression } ] ")"
```

说明：

- `await` 是一元运算符，右结合：`await await f()` 合法（少见）。
- 调用只支持函数调用形式 `f(args)`，**无** `obj:method()`、**无** `obj.field`。
- **无** 表构造、`and`/`or`/`not`、比较运算、多返回值。

## 语义要点（与转译相关）

- `async function` 的调用返回 **Task**（非直接返回值）。
- `await exp` 要求 `exp` 求值为 Task（或可被 `andThen` 的对象）；结果在状态机下一状态写入临时量。
- 函数内 `local` / 赋值的名字经 codegen 存入 `self._locals`，以便跨 await 保留。
