# 上线清单（生产就绪评估）

对照本仓库当前能力，区分 **已就绪**、**本阶段不做 / 延后**、**已知限制**。

## 已就绪（可依赖）

| 能力 | 说明 |
| --- | --- |
| 嵌入式 splice 转译 | `.alua` = Lua 宿主 + 顶层 `async function` → 状态机；无 `coroutine` |
| Task 三态 | `fulfilled` / `rejected` / `canceled` |
| `andThen` / `await_then` | 成功 / 失败 / 取消三路；缺省 cancel 向下游传播 |
| 微任务 | `Task.defer` / `Task.pump` |
| **定时与 Delay** | 内部定时器堆 + 虚拟时钟；`Task.delay` / `advance` / `now` / `set_clock`；可选 `Task.set_timer(cb, ms)` 宿主钩子 |
| 取消 | CTS / Token / `Cancellation.scope` + ambient `current`；`delay` 尊崇取消 |
| try / catch / finally / rethrow | async 体内跨 await |
| WhenAll / WhenAny | 见设计说明策略 |
| FromException 等 | `from_exception` / `faulted` / `from_canceled` / `canceled` |
| Forget | `task:forget()` / `Task.forget(task)`（类 async void，慎用） |
| 未观察拒绝 | 结算后无观察者 → `Task.on_unhandled_rejection`；可 `set_unhandled_rejection` |
| 示例与 demo | `lua run_demo.lua all` 全绿（含 P0 + P1） |
| 中文文档 | README、设计说明、语法、本清单 |

## 本阶段不做 / 明确延后

| 项 | 状态 | 备注 |
| --- | --- | --- |
| SynchronizationContext / 线程切换模型 | **won't-do（近期）** | Lua 单线程；无 .NET 式 SyncContext。宿主可用 `set_timer` + 自有循环 |
| `IAsyncEnumerable` / `await foreach` | **later** | 无生成器语法规划 |
| 编译期自动注入 ambient | **later** | 并行 `when_all` 请显式传 `ct` |
| 嵌套 `local async function`（透传区内） | **won't-do（splice 限制）** | 仅顶层 `async function`；从 Lua 调用已生成的 async 即可 |
| async 体内匿名 `function` 表达式 | **won't-do** | 方言子集；闭包放宿主透传区 |
| 完整 Lua 5.x 语法兼容（async 体内） | **won't-do** | 有意子集 |
| 真实 OS 线程 / 多 Lua State 调度 | **won't-do** | 协作式单线程泵 |
| Promise A+ 全兼容测试套件 | **later** | 行为接近但非目标 |

## 已知限制（使用时注意）

1. **虚拟时钟默认**：无 `set_clock` / `set_timer` 时，`Task.delay` 依赖 `Task.advance` 或 `pump` 触发到期堆项；生产宿主应 `set_timer` 或驱动 `advance`/`now`。
2. **`forget` 谨慎**：错误被吞掉，类似 C# `async void`；仅用于明确不关心结果的边车逻辑。
3. **ambient 取消非并行安全**：`Cancellation.current` 为进程级栈；`when_all` 并行请显式 token。
4. **WhenAny 不取消失败者**：其余 Task 仍会跑完（除非自行绑定同一 CTS）。
5. **package.path**：需能 `require("runtime.task")` 等（`run_demo.lua` / 转译输出约定相对仓库根）。
